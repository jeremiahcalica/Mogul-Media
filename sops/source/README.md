## Rules that are only in the narration (not in the written SOPs)

1. **The transcript must be the Markdown export.** "It is imperative to download the meeting transcript in MD file. Very, very, very, very important." (Loom 1, 2:05)
2. **The brief prompt is used verbatim.** "please in verbatim please" (Loom 1, 2:55). The exact text, read off the screen at 2:52:

   > Can you give me a detailed brief for the topics for Mason L based on this meeting with Kyle, where they talked about what to do per topic? Pay attention to detail. I also attached the topic sheet, I want you to name the brief according to its correct vehicle in the chat, make sure that you're paying attention to detail of the meeting so I don't miss details or instructions (include the pivots on the call, if any). Do not invent anything. Make sure you include the original brief in the topic sheet, and just write a "note" saying "pivot" (if there's any), so I know what was kept and what was changed or what was kept and what was killed.
   > In a claude doc pls

3. **Which topics go into the longform doc** (Loom 1, 3:20). NOT DISCUSSED + Type A means the client gave no answers, so the topic is left out. NOT DISCUSSED + Type B ("no answer needed") is drafted from material on file, so it stays in.
4. **The schedule prompt doesn't need to be verbatim.** "You don't have to take this verbatim. Write something like this" (Loom 1, 0:50). What was typed: "Claude, can you give me the updated topic and content batch? By now, there are already new topics (to be submitted next week) and long-form content batch as well, organize them like last time."
5. **The longform doc copy goes to My Drive, not the client's folder.** "instead of duplicating it inside this folder, what you're going to do is copy it to my drive" (Loom 2, 0:50). The written SOP agrees ("destination folder My Drive"). The Copy dialog defaults to the client's `2026` folder, so this has to be changed on purpose.
6. **Media Folder stays empty for now.** "keep it empty for now" (Loom 2, 1:15).
7. **One line per topic, using the topic's PERSPECTIVE field and its vehicle.** "take a look at the perspective here... just write it here... This is the vehicle, the long form vehicle... do the same for every topic" (Loom 2, 1:40–2:30).
8. **Bold, then space the lines out, then star the doc** "so it should appear on my starred" (Loom 2, 2:55–3:20).
